# 合同会社設立ナビ（houjin-navi）

合同会社（LLC）を**自分で設立する**ための手順・書類・届出期限を、公式情報の出典つきでナビゲートする、**インストール不要・無料・ローカル完結**の Web アプリです。

## できること
1. **会社形態かんたん診断**（合同会社／株式会社の向き不向き）
2. **設立ステップのチェックリスト＆進捗管理**（6ステップ＋設立後）
3. **書類ドラフトの自動生成**（定款／就任承諾書／払込証明書／設立登記申請書／登記すべき事項）
4. **設立後の届出・期限の自動計算**（年金5日・法人設立届2ヶ月 等）＋カレンダー(.ics)書き出し

## 使い方
1. `src/index.html` を**ブラウザで開くだけ**（ダブルクリック）。サーバー不要。
2. 最初に注意事項（免責・対象範囲）に同意。
3. 「基本情報入力」に商号・目的・資本金・代表社員・設立予定日などを入力。
4. 「書類を作る」でドラフトを生成 → 印刷/PDF・コピー。
5. 「届出・期限」で提出期限を確認 → `.ics` をカレンダーに登録。

入力内容は**この端末のブラウザ内（localStorage）だけ**に保存され、外部には一切送信されません。

## 重要な注意（最優先の設計方針）
本ツールは**情報提供の支援ツール**であり、法的助言・登記代理・税務代理ではありません。
- 生成物はすべて**ドラフト（下書き）**です。
- 制度・税率・様式は改正されることがあります（情報の最終確認日: **2026-07-11**）。
- 対象は「合同会社・金銭出資・社員1名」の標準ケース。株式会社／現物出資／法人が社員／許認可業種は対象外。
- **実際の提出前に、必ず公式情報および司法書士・税理士等の専門家でご確認ください。**

## 開発者向け
- 構成: `src/index.html` `src/app.js`（ロジック/純粋関数）`src/data.js`（制度データ）`src/app.css`
- テスト: `npm test`（= `node --test`）。純粋関数の単体テスト20件。
- 制度更新時は **`src/data.js` だけ**を更新し、`META.lastVerified` と `source` を差し替える。
- 詳細: `docs/SRS.md` `docs/SDD.md` `docs/TEST_PLAN.md` `research/`
