# 法人ナビ（houjin-navi）

**「自分に合う事業の形」を診断し、開業・設立の手続きまで導く、インストール不要・無料・ローカル完結の Web アプリです。**

法人化を考えているけれど「個人事業／合同会社／株式会社／一般社団法人のどれが自分に合うか分からない」——そんな人の入口になります。

## できること
1. **法人診断（10問・4セクション）** — 事業の形・お金・リスク・将来の観点で、4タイプの適合度を診断。「あなたに合いそうなのは○○」＋代替案＋見落としポイントを提示。
2. **手続きナビ（個人事業・合同会社に対応）** — ステップのチェックリスト、必要書類のドラフト自動生成、届出の期限自動計算＋カレンダー(.ics)出力。
3. **概要ガイド（株式会社・一般社団法人）** — 手続きの概要と公式情報リンク（詳細ガイドは順次対応）。
4. **診断のスキップ** — タイプが決まっている人は、入口から直接手続きへ。

診断で「気づき」を得られるよう、各質問に一次情報ベースの豆知識（社会保険の加入義務・無限責任・法人の維持コストなど）を添えています。

## 使い方
1. `src/index.html` を**ブラウザで開くだけ**（サーバー不要）。
2. 注意事項に同意 →「法人診断を受ける」or「タイプを選んで直接進む」。
3. 手続きナビで基本情報を入力 → 書類ドラフト生成／届出期限の確認。

入力内容は**この端末のブラウザ内（localStorage）だけ**に保存され、外部には一切送信されません。

## 重要な注意
本ツールは**情報提供の支援ツール**であり、法的・税務的な助言や登記代理ではありません。
- 診断結果は「向いている傾向」の**目安**です。生成物はすべて**ドラフト**です。
- 制度・税率・様式は改正されることがあります（情報の最終確認日: **2026-07-11**）。
- 手続きナビの対応: **個人事業・合同会社**（株式会社・一般社団法人は概要のみ／順次対応）。
- **最終判断・提出前に、必ず公式情報および税理士・司法書士等の専門家でご確認ください。**

## 対応タイプと手続きの状況
| タイプ | 診断 | 手続きナビ |
|---|---|---|
| 個人事業主 | ✅ | ✅ フル対応（開業届・青色申告） |
| 合同会社 | ✅ | ✅ フル対応（定款〜登記〜届出） |
| 株式会社 | ✅ | 🚧 概要のみ（順次対応） |
| 一般社団法人 | ✅ | 🚧 概要のみ（順次対応） |

## 開発者向け
- 構成: `src/index.html` / `src/app.js`（ロジック・診断エンジン・純粋関数） / `src/data.js`（診断定義＋制度データ） / `src/app.css`
- テスト: `npm test`（= `node --test`）。純粋関数の単体テスト20件（診断スコアリング・期限計算・書類生成 ほか）。
- **制度・診断の更新は原則 `src/data.js` だけ**を編集（`META.lastVerified` と `source` を更新）。タイプ追加も data 追加で対応可能な構造。
- デプロイ: GitHub `main` への push で Cloudflare Workers（Static Assets）へ自動デプロイ。
- 詳細: `docs/SRS.md` `docs/SDD.md` `docs/TEST_PLAN.md` `research/`
