# SRS — 合同会社設立ナビ（houjin-navi）

- 準拠: IEEE 29148 / ISO 25010
- 作成日: 2026-07-11 / 状態: Approved(自己レビュー) / バージョン: 1.0

## 1. はじめに
### 1.1 目的 (OBJ)
- **OBJ-001**: 個人が「合同会社（LLC）」を自力で設立するために、①意思決定 ②手続きステップ ③必要書類 ④設立後の届出期限 を、**法的に正確な出典付き情報**とともに一気通貫でナビゲートする。
- **OBJ-002**: 個人情報を外部に一切出さず（ローカル完結）、無料・インストール不要で完走できる。

### 1.2 スコープ
**IN SCOPE（MVP）**
- 合同会社（金銭出資・社員1名の標準ケース）の設立ナビ
- 会社形態の簡易意思決定サポート（合同 vs 株式）
- 基本情報入力→書類ドラフト自動生成（定款/就任承諾書/払込証明書/設立登記申請書/登記すべき事項）
- 設立日ベースの届出期限の自動算出＋ICSエクスポート
- 進捗のローカル保存

**OUT OF SCOPE**
- 株式会社の書類生成 / 現物出資・法人社員・許認可業種の個別対応
- 登記のオンライン申請そのものの代行、電子署名、e-Gov/登記・供託オンライン連携
- 税務・法務の個別助言（士業の独占業務）

**DEFER（将来）**
- プッシュ通知、自治体別期限DBの網羅、株式会社対応、多言語

### 1.3 定義
LLC=合同会社 / 定款=会社の基本規則 / 登記=法務局への設立登録 / 届出=設立後の官公庁提出。

## 2. 全体説明・ステークホルダー
| USR | 説明 | 権限 |
|---|---|---|
| USR-001 | 設立当事者（本人） | 全機能利用・自データ編集 |

成功指標: 「基本情報入力→5書類ドラフト生成→届出期限一覧表示」を**1セッション（目安30分以内）**で完了でき、全画面に出典と免責が表示されている。

## 3. 機能要件（FR）
記法: 各Must要件に Evidence / ACC / TC を接続（golden-rules #1,#2）。

### FR-SAFETY-001【Must】正確性ガード（最優先リスク対策）
- 本文: 全ステップ・全期限・全書類に一次情報URLと `最終確認日` を表示し、免責（情報提供であり法的助言・登記代理でない旨）を常時フッター表示、初回起動時に同意を得る。
- Evidence: EV-MOJ-001 / U3方針(research_v2)
- Given 任意の画面を表示 / When 描画完了 / Then 出典リンク・最終確認日・免責が可視である
- ACC-FR-SAFETY-001: 全主要画面に免責フッターと最終確認日(2026-07-11)が存在。届出/費用の各数値に出典リンクが紐づく。
- TC: TC-FR-SAFETY-001 / RISK-001

### FR-DEC-001【Should】会社形態 意思決定サポート
- 本文: 数問（信用重視/資金調達予定/設立コスト重視 等）に答えると合同会社・株式会社の向き不向きを出典付きで提示。
- Evidence: EV-FEE-001
- ACC-FR-DEC-001: 回答に応じて推奨形態と根拠（費用差・認証要否）が表示される。
- TC: TC-FR-DEC-001

### FR-STEP-001【Must】設立ステップのチェックリスト＆進捗
- 本文: 設立6ステップ＋設立後届出を一覧表示し、各項目を完了チェックでき進捗率を表示。
- Evidence: EV-STEP-001 / EV-MOJ-001
- Given ステップ一覧表示 / When 項目をチェック / Then 進捗率が再計算され保存される
- ACC-FR-STEP-001: 6ステップが正しい順序で表示。チェックで進捗%が更新。
- TC: TC-FR-STEP-001 / RISK-002

### FR-STATE-001【Must】ローカル永続化
- 本文: 入力値・進捗を `localStorage` に保存し、再訪時に復元。外部送信しない。
- Given データ入力後にリロード / When 再表示 / Then 入力値と進捗が復元される
- ACC-FR-STATE-001: リロード後も全入力・チェック状態が保持。ネットワーク送信ゼロ。
- TC: TC-FR-STATE-001 / RISK-003 / SEC-001

### FR-INPUT-001【Must】会社基本情報の入力
- 本文: 商号・事業目的・本店所在地・資本金・代表社員(氏名/住所)・事業年度・設立予定日を入力・検証。
- Evidence: EV-STEP-001 / EV-MOJ-001（登記すべき事項に一致）
- ACC-FR-INPUT-001: 必須項目未入力時に書類生成をブロックし、該当欄を明示。商号に「合同会社」を含む案内。
- TC: TC-FR-INPUT-001

### FR-DOC-001【Must】書類ドラフト自動生成
- 本文: 入力値から次のドラフトを生成: (a)定款 (b)代表社員就任承諾書 (c)払込証明書 (d)合同会社設立登記申請書 (e)登記すべき事項。各書類に「ドラフト・要最終確認」注記と根拠出典。
- Evidence: EV-MOJ-001
- Given 必須項目が入力済 / When 「書類を生成」 / Then 5書類のドラフトが入力値を差込んで表示される
- ACC-FR-DOC-001: 生成物に商号/目的/本店/資本金/社員/設立日が正しく反映。登記すべき事項が法務省の登記事項項目を網羅。
- TC: TC-FR-DOC-001 / RISK-001

### FR-DOC-002【Must】書類の印刷/PDF・コピー
- 本文: 各ドラフトを印刷（PDF保存）およびテキストコピーできる。印刷用CSSで整形。
- ACC-FR-DOC-002: 印刷プレビューに1書類が整形表示され、コピーで全文がクリップボードに入る。
- TC: TC-FR-DOC-002

### FR-REMIND-001【Must】届出期限の自動算出
- 本文: 設立日を基点に各届出（税務署/都道府県/年金事務所等）の期限日を算出し、締切順に一覧表示。全国共通の確度の高い期限のみ日数計算し、自治体依存は「要確認」表示。
- Evidence: EV-TAX-001 / EV-PEN-001
- Given 設立日=YYYY-MM-DD / When 期限計算 / Then 法人設立届出=+2ヶ月, 新規適用届=+5日 等が正しい日付で表示
- ACC-FR-REMIND-001: 設立日2026-08-01なら「新規適用届 期限2026-08-06(5日以内)」「法人設立届出書 期限2026-10-01(2ヶ月以内)」を表示。各行に出典。
- TC: TC-FR-REMIND-001 / RISK-001

### FR-REMIND-002【Should】ICSエクスポート
- 本文: 算出した期限を `.ics` としてダウンロードし、各自のカレンダーに登録できる。
- ACC-FR-REMIND-002: DLした.icsに各届出のVEVENT（期限日）が含まれる。
- TC: TC-FR-REMIND-002

## 4. 非機能要件（NFR / ISO 25010）
- **NFR-FUNC-001【Must】正確性**: 掲載数値・期限はリサーチでA/B二源以上一致のもののみ。出典必須。ACC=数値に出典URLが1:1で存在。TC-NFR-FUNC-001。
- **NFR-USE-001【Should】使用性**: 初見でも次に何をするか迷わない（現在ステップ強調・空状態文言）。ACC=各ステップに説明文と次アクションボタン。TC-NFR-USE-001。
- **NFR-PORT-001【Must】オフライン/可搬性**: ネット遮断でも全機能動作。外部CDN不使用。ACC=オフラインで書類生成・期限計算が動く。TC-NFR-PORT-001。
- **NFR-PERF-001【Should】性能**: 主要操作の応答 < 300ms（ローカル処理）。TC-NFR-PERF-001。
- **NFR-A11Y-001【Could】アクセシビリティ**: キーボード操作・コントラスト確保。

## 5. セキュリティ・法令
- **SEC-001【Must】**: 個人情報は `localStorage` のみ。外部送信・解析タグ・CDN読み込みを禁止。ACC=ネットワークタブでリクエスト0。TC-SEC-001。
- **SEC-002【Should】**: 「データを消す」操作を提供（localStorageクリア）。
- **法令**: 士業独占業務（登記代理・税務代理）を行わない。情報提供に限定（FR-SAFETY-001で担保）。
